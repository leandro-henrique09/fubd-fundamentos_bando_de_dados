📚 Fundamentos de Banco de Dados

Repositório destinado aos meus estudos sobre Fundamentos de Banco de Dados, utilizando como principal material o curso do Boson Treinamentos.

🎓 Curso: Fundamentos de Banco de Dados
▶️ Playlist: Curso no YouTube – Boson Treinamentos

🎯 Objetivo

Construir uma base sólida em Banco de Dados, entendendo não apenas como escrever consultas SQL, mas também como os bancos de dados funcionam, como seus dados são organizados e como projetar estruturas eficientes.

Principais objetivos
• Entender os fundamentos de bancos de dados
• Diferenciar banco de dados, SGBD e sistema de informação
• Compreender bancos relacionais e não relacionais
• Aprender modelagem de dados
• Entender entidades, atributos e relacionamentos
• Aprender conceitos de chaves e integridade
• Compreender normalização
• Aprofundar conhecimentos em SQL
• Entender índices e otimização
• Conhecer transações e propriedades ACID
• Entender conceitos básicos de segurança e controle de acesso
• Desenvolver uma visão de banco de dados voltada para Dados e Data Engineering
